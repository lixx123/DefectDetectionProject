# ImageJ灰度拉伸与滤光片弱疵病补漏实验方案

## 1. 实验定位

本实验是当前固定双阈值检测链的漏检诊断，不修改生产算法。目标是确认：ImageJ线性灰度拉伸后人工可见、但当前自动检测未输出的暗细节，是否在原始RAW DN中具有可重复的暗异常证据。

可能原因分为四类：
1. 固定阈值偏高，弱响应候选未形成；
2. Black-Hat尺度与异常宽度不匹配；
3. 工作带背景梯度、边缘或条带结构；
4. 探测器纹理或随机噪声。

## 2. 输入和硬约束

- 分别处理26_1、26_2原始12 bit RAW。
- 使用K8A工作带Mask，仅在WORK/BAND_EDGE区域观察。
- 读取冻结J5、K8B、K8C、K8D和最终对象结果用于来源匹配。
- RAW只读。ImageJ的Brightness/Contrast只用于显示，禁止Apply覆盖原始DN。
- 两帧坐标和候选独立，不复制候选坐标。
- 所有新增人工观察区域先记为VISUAL_WEAK_REVIEW，不自动认定疵病。
- 保存输入RAW SHA256、配置、Mask版本和输出文件清单。

## 3. ImageJ灰度拉伸

对每一条工作带单独计算RAW DN分布，采用线性映射：

`I8 = 255 * clip((DN-L)/(U-L), 0, 1)`

比较三档显示范围：

| 方案 | L | U | 用途 |
|---|---|---|---|
| Stretch-1 | P0.1 | P99.9 | 温和拉伸 |
| Stretch-2 | P0.5 | P99.5 | 主要观察 |
| Stretch-3 | P1.0 | P99.0 | 强拉伸、观察噪声放大 |

百分位仅用于显示，不是检测阈值。相同工作带所有ROI必须使用同一组L/U，禁止对每个ROI单独自动拉伸后比较DN深浅。首轮只做线性拉伸，不叠加CLAHE、Gamma、锐化或降噪。

## 4. ROI选取

每条工作带覆盖四类区域：
- 当前最终中/大疵病；
- K8B补充候选和K8C/K8D待复核候选；
- 拉伸后人工发现、但J5/K8B无对应来源的视觉新增区域；
- 条带边缘、背景过渡、纹理密集区和无明显异常的背景对照区。

不能只选已知疵病附近区域，避免选择偏差。

## 5. 视觉新增候选的RAW核查

每个候选在原始RAW DN上计算：
- 候选DN中位数；
- 背景环DN中位数；
- 绝对DN差；
- 背景MAD；
- 相对暗度；
- MAD归一化显著性；
- 面积、长宽比、主方向和局部连通性。

描述性统计：

`DeltaDN = Median(DN_bg) - Median(DN_cand)`

`Z_MAD = DeltaDN / max(3, 1.4826 * MAD(DN_bg))`

背景环需排除其他候选和工作带边缘。参考像素不足时标记RAW_REFERENCE_INVALID，不强行计算。上述统计首轮只用于分析，不直接制定新的生产阈值。

## 6. 与冻结检测结果匹配

每个视觉候选必须归入：
- MATCH_FINAL_OBJECT
- MATCH_J5_SOURCE
- MATCH_K8B_SUPPLEMENT
- MATCH_REVIEW_ONLY
- NO_EXISTING_SOURCE

重点研究NO_EXISTING_SOURCE。匹配必须基于同一RAW、同一工作带和全局坐标，不能仅凭显示图上的视觉距离判断。

## 7. 后续算法分支决策

- RAW暗异常存在但Black-Hat响应不足：研究结构元素尺寸与异常宽度的匹配；
- Black-Hat响应存在但低于170 DN：开展局部阈值补充试验，与固定阈值主通道并行且可回退；
- RAW对比度和DoG/形态证据不稳定：保留复核，不直接降阈值；
- 主要位于工作带边缘或背景梯度：完善边界保护，不作为疵病补漏；
- 单像素/极小暗点：进入独立微小候选审计，不静默删除。

## 8. 交付文件

- stretch_config.csv：各帧/工作带的显示上下限和参数；
- visual_weak_candidate_review.csv：人工新增候选坐标、工作带、来源匹配及复核状态；
- raw_dn_profiles.csv：候选/背景原始DN统计；
- 每工作带三档拉伸图和代表ROI联系图；
- source_manifest.json：RAW、Mask和配置SHA256；
- comparison_to_frozen_final.csv：视觉候选与冻结检测结果的对应关系。

## 9. 验收标准

1. 同一工作带使用统一显示窗口后，细节可重复观察；
2. 新增区域具有可量化的RAW暗差和空间结构；
3. 能排除条带边缘、背景纹理和随机噪声等干扰；
4. 明确是否存在J5/K8B均未覆盖的来源；
5. 人工确认后形成独立、可复现的补漏案例。

本方案仅定义实验流程，未执行ImageJ实验，不改变当前正式生产算法。
