# Phase 6 交互约定

1. Ctrl+O 打开 RAW，显示名称、大小、本地路径，清理上一任务。路径仅运行时可见。
2. 开始/重新检测调用 Controller → InspectionService → Detector，不在主线程检测。仅 AUTO 普通操作；不暴露调试算法按钮。
3. 忙碌状态禁用打开、历史、开始、重新检测、保存和视图切换，显示无限进度条，不编造百分比。完成/异常恢复。
4. 成功先展示临时结果。Ctrl+S 正式保存，成功禁用再次保存。Repository 错误简短显示于状态栏及资源提示，完整日志在 output/runtime/gui_errors.log。
5. 历史结果选择器 QDialog+QTableView，时间/文件/样本/对象数/面积/模式/回退列，双击通过 Repository.load 读取。
6. 表格仅最终 Defect[]。点击行按 ID 定位、框高亮并更新详情；图上点击框反向选行。排序使用数值角色，ID 不承担空间顺序。适应/1:1/缩放后选择仍按原始坐标。
7. 物理字段读取历史存储值，尺度/来源来自 calibration_info，不读取当前全局尺度重算。无效 Calibration 隐藏 μm/μm²，保留像素量。长度标为 Max Feret。
8. ROI_BH QA 失败后 FULL 成功显示“检测完成（已自动切换至全图模式）”及原因。双失败由服务 final gate 拒绝。
9. 关闭时若任务忙则保留窗口并在状态栏提示，完成后可正常退出。无强杀和孤儿子进程风险操作。

截图及脚本交互用于工程 QA，不等同于人工验收。人工审核需确认布局、真实操作手感和现场 RAW 操作；本轮不重跑真实检测。
